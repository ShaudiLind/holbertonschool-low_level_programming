# C - Pointers, Arrays and Strings

## Description
This project is about learning how to work with pointers, arrays, and strings in C. It focuses on understanding how memory addresses work and how to manipulate values through pointers.

## Learning Objectives
- What are pointers and how to use them
- What are arrays and how to use them
- The differences between pointers and arrays
- How to use and manipulate strings
- The scope of variables

## Requirements
- Allowed editors: vi, vim, emacs
- All files will be compiled on Ubuntu 20.04 LTS using gcc
- Compilation flags: -Wall -Werror -Wextra -pedantic -std=gnu89
- All files should end with a new line
- Code should follow the Betty style
- No global variables
- No more than 5 functions per file
- The only allowed C standard library function is `_putchar`

## Files
- `0-reset_to_98.c` - Function that takes a pointer to an int and updates the value it points to 98.
- `main.h` - Header file containing function prototypes

## Compilation Example
```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 0-reset_to_98.c main.c -o output
