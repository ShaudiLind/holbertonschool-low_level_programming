# C - Recursion

This project focuses on understanding and implementing recursion in the C programming language. Recursion is a programming technique where a function calls itself to solve smaller instances of a problem.

## Learning Objectives
- Understanding what recursion is.
- How to implement recursion in C.
- Determining when to use recursion and when to avoid it.
- Adhering to strict coding standards (Betty style, no loops, no static variables).

## Requirements
- All files are compiled on Ubuntu 20.04 LTS using `gcc` with flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- All code follows the Betty coding style.
- No global variables are allowed.
- No loops (for, while, do-while) are allowed.
- No standard library functions (like `printf`, `puts`) are allowed, except for `_putchar`.
- Each file must end with a new line.

## Tasks
- **0. She locked away a secret...**: Write a function that prints a string, followed by a new line, using recursion.
