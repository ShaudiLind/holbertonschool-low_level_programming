# C - Function Pointers

This directory contains exercises for the **Function Pointers** project in C from Holberton School.

## Description

The purpose of this project is to learn how to use **function pointers** in C, how they work, what they store, and where they point in memory.

A function pointer allows you to store the address of a function in a variable and use that variable to call the function later.

## Learning Objectives

At the end of this project, I should be able to explain, without the help of Google:

- What function pointers are and how to use them
- What a function pointer exactly holds
- Where a function pointer points in virtual memory
